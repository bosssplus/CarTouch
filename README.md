## ۱. معرفی پروژه

**CarTouch** یک سیستم کنترلی برای خودرو است که با استفاده از **ESP32-S3** و **CAN Bus** (شبکه داخلی خودرو) امکان کنترل و مانیتورینگ خودرو را فراهم می‌کند.

### قابلیت‌های اصلی:
- **کنترل لمسی** از طریق صفحه TFT 2.4 اینچ داخل خودرو (روش اصلی)
- **کنترل از راه دور** از طریق Web Dashboard با WiFi (روش مکمل)
- **قفل/باز کردن** درب‌ها (۴ درب + صندوق عقب)
- **بالا/پایین بردن** شیشه‌ها (۴ شیشه + سانروف)
- **کنترل آینه‌ها و دزدگیر**
- **نمایش اطلاعات خودرو** (سرعت، RPM، دمای موتور، ولتاژ باطری، سطح سوخت)
- **خواندن کدهای خطا** (DTC) از ECU خودرو
- **حالت Listen-Only** (فقط خواندن بدون ارسال فرمان)
- **Auto Sleep** بعد از ۱۰ دقیقه بی‌فعالیتی (حفظ باطری خودرو)
- **بیدار شدن خودکار** با دریافت پیام CAN
- **پشتیبانی از ۳۰۰+ مدل خودرو** از طریق OpenDBC
- **حالت شب/روز** خودکار

## ۳. سیم‌بندی و اتصالات

### ۳.۱. اتصال صفحه TFT به ESP32-S3

| پین TFT | پین ESP32-S3 | توضیحات |
|---------|--------------|---------|
| **CS** | GPIO10 | Chip Select |
| **DC** | GPIO7 | Data/Command |
| **RST** | GPIO4 | Reset |
| **MOSI** | GPIO11 | SPI Data In |
| **SCLK** | GPIO12 | SPI Clock |
| **MISO** | GPIO13 | SPI Data Out |
| **BL** | GPIO21 | Backlight (PWM) |
| **VCC** | 3.3V | تغذیه 3.3V |
| **GND** | GND | زمین مشترک |

### ۳.۲. اتصال تاچ (XPT2046)

| پین تاچ | پین ESP32-S3 | توضیحات |
|---------|--------------|---------|
| **T_CS** | GPIO14 | Touch Chip Select |
| **T_DIN** | GPIO11 (MOSI) | (اشتراکی با TFT) |
| **T_DOUT** | GPIO13 (MISO) | (اشتراکی با TFT) |
| **T_CLK** | GPIO12 (SCLK) | (اشتراکی با TFT) |

> **نکته**: تاچ معمولاً با TFT اشتراک SPI دارد و فقط CS جدا است.

### ۳.۳. اتصال ماژول CAN (SN65HVD230)

| پین ماژول CAN | پین ESP32-S3 | توضیحات |
|--------------|--------------|---------|
| **VCC** | 3.3V | تغذیه ماژول |
| **GND** | GND | زمین مشترک |
| **CTX** | GPIO9 | CAN Transmit |
| **CRX** | GPIO6 | CAN Receive |
| **R** | GPIO- | اختیاری (مقاومت ترمینال) |

### ۳.۴. اتصال به CAN Bus خودرو

**روش اول - از طریق OBD-II (توصیه شده):**

پورت OBD-II معمولاً زیر فرمان یا کنار جعبه فیوزها قرار دارد.

| پین OBD-II | علامت | توضیحات |
|-----------|-------|---------|
| **پین ۶** | CAN-H | خط High CAN Bus |
| **پین ۱۴** | CAN-L | خط Low CAN Bus |
| **پین ۴** | GND | زمین خودرو |
| **پین ۱۶** | 12V+ | ولتاژ باطری (برای تغذیه) |

اتصال به ماژول SN65HVD230:
- **CAN-H** OBD-II ← **CAN-H** ماژول SN65HVD230
- **CAN-L** OBD-II ← **CAN-L** ماژول SN65HVD230

**روش دوم - اتصال مستقیم به سیم‌های CAN (فقط برای متخصصان):**

می‌توانید مستقیم به سیم‌های CAN Bus در هر نقطه از خودرو متصل شوید:
- سیم **CAN-H** معمولاً **نارنجی-مشکی** یا **سفید**
- سیم **CAN-L** معمولاً **نارنجی-قهوه‌ای** یا **آبی**

> **⚠️ هشدار**: قبل از قطع باتری خودرو را جدا کنید. اتصال اشتباه CAN-H و CAN-L می‌تواند به ماژول آسیب بزند.
